f/2 — ABOUT

Two crafts, one eye for detail

I'm a creative professional and web developer who never fully chose between a camera and a keyboard — so I kept both. What started as documenting friends' events with a borrowed DSLR grew into a full practice spanning photography, videography, and software, and each discipline quietly sharpens the other. Composition rules that guide a photograph guide a layout. The patience of a long edit session guides a long debugging session.

On the technical side, I build clean, responsive interfaces with HTML, CSS and JavaScript, and write Python for the logic behind the scenes — from small automation scripts to full data-driven applications. On the creative side, I plan, shoot and edit photography and video for events, portraits, brands and personal projects, always aiming for work that feels considered rather than convenient.

Whatever the medium, the goal is the same: notice what matters, frame it clearly, and ship it well.
